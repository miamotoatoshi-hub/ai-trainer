## Фаза 0 — Фундамент

### Что мы сделали и как это работает

Мы построили «пустой дом»: стены и проводка есть, мебели ещё нет. Приложение уже открывается,
у каждого экрана есть свой адрес, а проверки следят, чтобы ничего не сломалось.

- **Next.js** — главный каркас. Папка `app/` устроена так: одна папка = один адрес.
  Файл `app/(tabs)/chats/page.tsx` — это адрес `/chats`. Скобки `(tabs)` — просто группа,
  в адресе их нет.
- **TypeScript** — JavaScript, который проверяет ошибки до запуска. Если перепутать
  число и текст, он ругнётся сразу, а не когда приложение упадёт у пользователя.
- **Tailwind** — способ красить экраны короткими «наклейками» прямо в разметке.
  Настоящие цвета и шрифты ПИНКА подключим в Фазе 1.
- **Локализация** — все надписи лежат в `locales/ru.json`, а в коде мы просим их по
  ключу: `t("screens.chats")`. Так позже добавим английский, не переписывая экраны.
- **Проверки (три сторожа):**
  - `pnpm lint` читает код и ищет опасные места;
  - `pnpm test` (Vitest) проверяет логику — быстро, без браузера;
  - `pnpm test:e2e` (Playwright) открывает настоящий браузер и ходит по экранам.
- **Секреты** лежат в `.env.local`, а в git попадает только `.env.example` без значений.

```
  Ты открываешь адрес  ->  Next.js ищет папку в app/  ->  показывает page.tsx
        /chats                app/(tabs)/chats/            "Тренеры" (заглушка)
                                     |
                       тексты берутся из locales/ru.json
```

### Что проверить руками

1. `pnpm install`, затем `pnpm dev` — открыть http://localhost:3000, должно перекинуть на `/chats`.
2. Открыть вручную: `/workouts`, `/rating`, `/profile`, `/chat/gromov`, `/call/1`, `/result/1`, `/onboarding`.
3. `pnpm test` и `pnpm lint` — без ошибок.
