# ПИНОК

Мобильное веб-приложение (PWA) с AI-тренерами с характером. Тренировка — это видеозвонок:
тренер видит тебя через камеру, считает повторения и ругает за плохую технику.

Главное техническое задание: [docs/MASTER_PROMPT.md](docs/MASTER_PROMPT.md).
Учебник «что мы сделали и как это работает»: [docs/LEARNINGS.md](docs/LEARNINGS.md).

## Как запустить

Нужно: **Node.js 20.9+** (лучше актуальная LTS) и **pnpm 10**.
Если pnpm нет: `corepack enable` (он поставится сам по версии из `package.json`).

```bash
pnpm install          # поставить зависимости
cp .env.example .env.local   # ключи (для Фазы 0 пустой файл — это нормально)
pnpm dev              # открыть http://localhost:3000
```

Сайт откроется на `/chats` — пока это заглушка. Настоящие экраны появляются по фазам.

## Команды

| Команда          | Что делает                                                 |
| ---------------- | ---------------------------------------------------------- |
| `pnpm dev`       | запускает приложение для разработки                        |
| `pnpm build`     | собирает рабочую версию (проверяет, что всё компилируется) |
| `pnpm start`     | запускает собранную версию                                 |
| `pnpm lint`      | ищет ошибки и опасные места в коде (ESLint)                |
| `pnpm typecheck` | проверяет типы TypeScript                                  |
| `pnpm format`    | приводит код к единому виду (Prettier)                     |
| `pnpm test`      | юнит-тесты логики (Vitest)                                 |
| `pnpm test:e2e`  | тесты экранов в настоящем браузере (Playwright)            |

Перед первым `pnpm test:e2e` на своём компьютере один раз поставь браузер:
`pnpm exec playwright install chromium`.

## Секреты

Ключи (Anthropic, ElevenLabs, Supabase, …) лежат **только** в `.env.local` — этот файл
в `.gitignore` и никогда не попадает в git. В `.env.example` — список всех переменных и
подсказки, где взять каждый ключ. Нет ключа — приложение работает на заглушке.

## Структура

```
app/            экраны и серверные роуты (Next.js App Router)
components/     кнопки, чат, оверлей тренировки
lib/            логика: поза, упражнения, тренеры, отношения, уведомления, Supabase
content/        тренеры: характер, фразы, аватары
locales/        все тексты интерфейса (ru.json)
design/         HTML-макеты (необязательно), эталон внешнего вида
scripts/        генерация фраз, озвучка, сиды
supabase/       миграции базы данных
tests/          юнит-тесты (*.test.ts) и e2e (tests/e2e/*.spec.ts)
docs/           ТЗ и учебник
```
