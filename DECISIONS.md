# DECISIONS — решения, принятые по ходу

Формат: одна строка на решение. Здесь же — «зачем» для каждой новой зависимости.

## Процесс

- Репозиторий уже инициализирован в Фазе 0 (ветка `claude/dreamy-shannon-rxfn8d`), поэтому `git init` не нужен: продолжаем в той же истории, без переписывания и без force-push.
- Главный экран «Тренеры» теперь на `/` (в Фазе 0 был `/chats`). Папка `app/(tabs)/chats` и редирект убраны.
- Коммит после каждого этапа и `git push` в ту же ветку; PR не создаю, пока владелец не попросит.

## Версии и зависимости (зачем)

- TypeScript 6.0 и ESLint 9: `eslint-config-next` 16.4 пока не поддерживает TS 7 и ESLint 10.
- `dexie` — удобная обёртка над IndexedDB: все данные хранятся на устройстве, без аккаунтов.
- `@mediapipe/tasks-vision` — распознавание позы прямо в браузере (видео не уходит на сервер).
- `@anthropic-ai/sdk` — серверный роут чата; без ключа не вызывается.
- `web-push` — настоящий Web Push, подключается только если в `.env.local` есть VAPID-ключи.
- `fake-indexeddb` (dev) — тесты сервисов поверх настоящего Dexie без браузера.
- `tsx` (dev) — запуск TypeScript-скриптов (`scripts/synthesize-phrases.ts`).

## Данные и архитектура

- Весь доступ к данным — через интерфейс `Repository` (`lib/data/repository.ts`); сейчас реализация на Dexie, позже заменяется на Supabase без правки экранов.
- Экраны подписываются на изменения через собственный хук `useRepoData` (без `dexie-react-hooks`), чтобы Dexie не «протекал» в компоненты.
- Нет аккаунтов, поэтому «пользователь» для серверных лимитов = случайный `anonId`, который создаётся при первом запуске и лежит в IndexedDB.
- «Сервер» чата получает контекст (профиль, сводку тренировок, последние сообщения, память) в теле запроса от клиента: данные живут на устройстве, сервер ничего не хранит.
- Дневные лимиты (чат 60, голос 20) считаются и на клиенте (IndexedDB), и на сервере (в памяти процесса по `anonId`).

## Продукт

- Пол пользователя неизвестен, поэтому в репликах тренеров по возможности нет форм прошедшего времени с родом («ты сделал/сделала»).
- Аватары — React/SVG-код в `content/coaches/<id>/avatar.tsx` с функцией «SVG-строка» (нужна, чтобы рисовать аватар на canvas в клипе).
- Фраза считается подходящей жёсткости, если её уровень входит в поле `h` (`"1-3"`, `"2-3"`, `"3"`).
- Неглубокий присед (до 100–130°) не засчитывается как повтор, но помечается и штрафует процент чистых: чистота = чистые / (засчитанные + неглубокие).
- Планка и другие «временные» упражнения считают единицей секунду: чистая секунда = секунда без ошибок.
- Клип: вместо кольцевого буфера с «склейкой» (MediaRecorder так не умеет) пишем независимые сегменты по 15 с и храним лучший по «смешному весу». Голос тренера попадает в клип только если играет через Web Audio (ElevenLabs); браузерный синтез речи записать нельзя.
- Перед камерой в онбординге добавлен короткий экран «мне 13+ и правила безопасности» (ТЗ требует экран здоровья перед первой тренировкой, а вопрос возраста стоит после приседаний).
- Игнор и «уколы» считаются при открытии приложения и раз в минуту, пока оно открыто; системные уведомления приходят, пока вкладка/PWA жива. Настоящий Web Push без сервера-хранилища подписок возможен только как тестовый.
- Фразы тренеров: формат `["текст", "жёсткость", "упражнение?"]`; id генерируются из порядка (`gromov.rep_good.003`), поэтому новые фразы дописываем в конец списка — озвученные mp3 остаются валидными.
- Банки: по 15–16 фраз на каждое из 18 событий из ТЗ и по 10–11 на три дополнительных (провис таза, таз вверх, колено за носок) у каждого тренера — всего более 1200 фраз; тест проверяет объём, отсутствие мата и оскорблений тела, эмодзи и «угадывания пола».
- Голоса ElevenLabs в `voice.json` — готовые голоса из библиотеки (ID из публичной документации); их можно заменить в файле или через `ELEVENLABS_VOICE_<ТРЕНЕР>`. Без ключа работает браузерный синтез (тембр и скорость настраиваются в `voice.json`).
- Счёт повторений звучит отдельным каналом и не перебивает говорящего; на сильном ускорении симулятора часть слов пропускается — так и задумано.
- Время тренировки в итоге — длительность самой тренировки без пауз и настройки камеры; `startedAt` пересчитывается при завершении.
- Планы можно подменить параметром `?plan=<id>` на экране звонка (например `quick-check`, `first-squats`) — удобно для проверки и демо.
- Манифест озвучки `public/voices/manifest.json` лежит в git (пустой список), сами mp3 — нет.
- Штраф «день без тренировки» считается от последней тренировки с любым тренером (но не раньше, чем тренер открылся, и не раньше создания профиля); отсчёт общий, а не по каждому тренеру отдельно.
- Чат: нейросеть отвечает через `/api/chat` структурным JSON (`output_config.format`), без принудительного tool-use; ответ проверяется на форму и правила безопасности, при нарушении — одна повторная попытка, затем заготовленная реплика. Системный промпт (характер + правила) стабилен и кэшируется; всё меняющееся (время, очки, память) идёт в сообщении пользователя.
- Сообщения про боль, еду/тело и кризис нейросеть не получает вообще: на них отвечает приложение проверенным текстом (`safety.*` в locales), игнор при этом снимается, а при кризисе «уколы» и игнор выключаются на 7 дней.
- В звонке нейросеть не используется (задержка и стоимость): реплики пользователя голосом получают мгновенный ответ из заготовок по ключевым словам; боль/кризис ставят звонок на паузу.
- «Пока тебя не было»: утро (09:00), напоминание (за 30 минут), подталкивание (через 20 минут после времени), холодный вечер (21:00, только если игнор уже закончился). Лимит 2 в день (3 в неделю в режиме «редко»); при нехватке места важнее напоминание и подталкивание. Эти же правила станут основой уведомлений.
- Телефон доверия на `/support` — российский (8-800-2000-122) и 112; номера лежат в `content/support-resources.json`, их надо проверить перед запуском для других стран.
- Жёсткость жёстко ограничивается возрастом на уровне хранилища (`clampHarshness`): до 18 лет не выше 2, пока возраст неизвестен — тоже не выше 2.
- Знакомство: приветствие → экран «13+ и здоровье» (галочка обязательна, при «мне нет 13» ничего не сохраняется) → 10 приседаний перед камерой (можно «пока без камеры») → анкета-переписка (имя, возраст, цель, минуты, дни, время, жёсткость, информация о тренерах, уведомления). Регистрации нет (гостевой режим, всё на устройстве); выбор тренера на старте не предлагается, потому что открыт только Громов.
- Пока знакомство не пройдено, все экраны кроме `/onboarding`, `/call`, `/result`, `/support` перенаправляют на знакомство; содержимое при этом рендерится на сервере, но скрыто (так HTTP-статус 404 для несуществующих страниц остаётся настоящим). Прогресс анкеты хранится на устройстве, поэтому её можно прервать и продолжить.
- Playwright по умолчанию запускается в один поток: видео-тесты (поза, ускоренный звонок) в два потока иногда мешают друг другу; `PW_WORKERS=2` включает ускорение.
- Клипы: запись идёт независимыми отрезками по ~15 секунд (холст 9:16 с видео, аватаром, счётчиком, субтитром и логотипом → MediaRecorder); в конце остаётся отрезок с самым «смешным» моментом. Размер 720×1280, а на мощных устройствах 1080×1920; формат mp4, если браузер умеет, иначе webm. Хранятся 5 последних клипов, только на устройстве. Звук клипа — только голос тренера из готовых mp3 (микрофон не пишется); голос браузера (speechSynthesis) в запись не попадает, поэтому без ключа ElevenLabs и без `pnpm synthesize` клип выходит с субтитрами, но без озвучки.
- Перед первым «Поделиться»/«Сохранить» показывается экран «Проверь кадр»; «Поделиться» открывает системное меню с файлом, а если браузер так не умеет — скачивает файл.
- Рейтинг и дуэли без сервера: всё нужное лежит в ссылке `/join?d=…` (друг: имя и чистые повторения недели; дуэль: имя, упражнение, секунды, результат; ответ: результат друга). Ссылки проверяются и ограничиваются (счёт 0–999, имя как в анкете), но подделать цифры может любой: для дружеского соревнования это нормально, для призов нужен сервер. Таблица недели = ты + друзья по их последней присланной ссылке (цифры прошлой недели помечены «устарели» и считаются нулём). Публичный id для ссылок отдельный, не anonId.
- Дуэль: минута приседаний (`duel:squat:60`) — один подход с таймером, считаются чистые повторения; прерванная минута не засчитывается. После результата тренер комментирует исход (`content/rating-lines.json`).
- Свободные тренировки: планы собираются на лету из адреса (`free:<упражнение>:quick|standard`, `duel:…`), в расписание не попадают.
- Профиль: изменения сохраняются сразу (кроме имени и расписания — там кнопка «Сохранить»); возраст до 18 лет автоматически понижает жёсткость; «Выйти из демо» и «Удалить все данные» — одно и то же (аккаунтов нет, выход = стереть данные на устройстве). Политика и условия — черновики (`content/legal.json`) с пометкой «проверить юристом».
- Ссылка друга для новичка запоминается: после знакомства человек возвращается на `/join`.
